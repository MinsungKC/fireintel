# fireintel

# FEATURES

- Up to date satellite imagery (refreshed every 10 minutes)
- GOES-19 EAST and WEST hotspots (also refreshed every 10 minutes)
- Aircraft layer and (partially) working filter
- NEXRAD radar for national, regional, and local radar.
- NWS API implementation as well as other weather sources (...)
- Live weather layers
- Frame playback
- Fuel types overlay
- AND MORE
